# OAuthSetup
      
      Steps to setup the code on a local machine
 
     # Setup Client
     1. Clone the repo.
     2. Run command "npm install"
     3. Configure the .env file in the root directory of the repo.
     4. then run command "npm start" to run in a development server.
     5. listen to http://localhost:3000
     
     
     # Setup Server
     1. Clone the repo.
     2. Run command "npm install"
     3. Configure the .env file in the root directory of the repo.
     4. then run command "nodemon index" or "node index"
     5. listen to http://localhost:8000
